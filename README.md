# Portfolio

My personal portfolio website — a single-page site built from scratch with **HTML, CSS and vanilla JavaScript** to introduce myself, show what I'm learning, and showcase my projects.

🔗 **Live site:** https://awaba-dev.github.io/portfolio/

## Features

- Responsive one-page layout (About, Skills, Projects, Contact)
- Light/dark theme toggle, remembered between visits
- Smooth scrolling navigation
- No frameworks or dependencies — pure HTML/CSS/JS

## Tech stack

`HTML` · `CSS` · `JavaScript`

## Running it locally

This is a static site, no build step required.

```bash
git clone https://github.com/awaba-dev/portfolio.git
cd portfolio
open index.html
```
